# Grade 5 Units 2–5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add fully selectable, source-audited Grade 5 Units 2–5 to the existing Luna text and Pipecat voice tutor without regressing Unit 1.

**Architecture:** Preserve the deterministic Teaching Engine and place a deep curriculum registry plus a unit-aware turn router at the seam currently occupied by the single Unit 1 curriculum. Author each Unit as validated YAML from exact workbook cells, expose unit metadata and session selection through the HTTP interface, and let web and voice use the persisted session `unit_id` as their single source of truth.

**Tech Stack:** Python 3.12, Pydantic, PyYAML, openpyxl, FastAPI, SQLite, pytest, Next.js 16, React 19, TypeScript, Vitest, Playwright, Pipecat.

**Spec:** `docs/superpowers/specs/2026-09-20-grade5-units-2-5-design.md`

## Global Constraints

- Workbook source of truth: `docs/Global_Success_Khung_Nghe_Noi_3_Level_v3.xlsx`, sheet `Lớp 5 (3 Level)`, ranges Unit 2 `A5:M7`, Unit 3 `A8:M10`, Unit 4 `A11:M13`, Unit 5 `A14:M16`.
- Keep the eight-stage order `warm-up`, `lesson-01`, `lesson-02`, `lesson-03`, `level-02`, `level-03`, `free-talk`, `summary`.
- Every taught vocabulary target gets one `vocabulary_introduction` activity with two model repetitions, one learner opportunity, feedback, and at most two attempts.
- Lesson 3 reviews Lesson 1–2 objectives and creates no new Lesson 3 objectives.
- Engine owns correctness, attempts, progression, and next objective; Teacher naturalizes bounded guidance and chooses varied praise wording.
- Text transcript cannot establish phoneme or stress accuracy; pronunciation claims require audio evidence.
- Unit 2 practices only fictional addresses and must not repeat or retain a child's real address.
- Unit 3 uses fictional foreign-friend identities; Unit 4 never requests Internet account details.
- Do not change STT, TTS, LLM providers or dependencies.
- Preserve stored Unit 1 sessions and Unit 1 behavior.

## Review Focus

- Workbook normalization: `numbers 23, 38, 93, 116` must yield four number targets and no target named `numbers 23`; Task 1 pins it.
- Slash groups: Unit 4 `percussion/wind/string instruments` must yield three intentional groups without corrupting other slash-bearing patterns; Task 1 pins it.
- Cross-unit routing: a persisted Unit 3 session must never be handled by Unit 1 or Unit 2 curriculum, including after resume; Task 5 pins it.
- Privacy: Unit 2 address practice must use fictional examples and redaction must prevent echo/storage of a supplied real address; Tasks 4 and 7 pin it.
- Stale/unknown units: API requests and persisted sessions referencing an unavailable unit must fail explicitly, never fall back to Unit 1; Tasks 2 and 5 pin it.

```python
def _split_vocabulary(text: str, *, grade: int, unit: int, row: int, column: int) -> list[str]:
    items = [item.strip() for item in re.split(r'[,;\n]', text) if item.strip()]
    if (grade, unit, column) == (5, 2, 4) and items and items[0].startswith('numbers '):
        items[0] = items[0].removeprefix('numbers ').strip()
    if (grade, unit, column) == (5, 4, 8):
        expanded = []
        for item in items:
            if item == 'percussion/wind/string instruments':
                expanded.extend(['percussion instruments', 'wind instruments', 'string instruments'])
            else:
                expanded.append(item)
        items = expanded
    return items
```

```python
@dataclass(frozen=True)
class UnitSummary:
    id: str
    grade: int
    unit: int
    title: str

class UnknownUnitError(LookupError):
    pass

class CurriculumRegistry:
    def __init__(self, root: Path, allowed_ids: tuple[str, ...]):
        loaded = {}
        for unit_id in allowed_ids:
            grade, unit = _parse_unit_id(unit_id)
            curriculum = load_unit(root / f'grade-{grade:02d}' / f'unit-{unit:02d}')
            if curriculum.id != unit_id:
                raise ValueError(f'Curriculum ID mismatch for {unit_id}')
            loaded[unit_id] = curriculum
        self._units = loaded

    def get(self, unit_id: str) -> UnitCurriculum:
        try:
            return self._units[unit_id]
        except KeyError as error:
            raise UnknownUnitError(unit_id) from error
```

Replace the abbreviated `list_units` line in the sketch with this implementation:

```python
    def list_units(self) -> tuple[UnitSummary, ...]:
        return tuple(
            UnitSummary(id=item.id, grade=item.grade, unit=item.unit, title=item.title)
            for item in sorted(self._units.values(), key=lambda value: (value.grade, value.unit))
        )
```

Do not expose filesystem paths, cache mutation, or per-unit convenience methods.
