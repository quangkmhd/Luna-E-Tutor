# Grade 3 Unit 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run Grade 3 Unit 1 “Hello” through the existing complete Luna text and voice journey with grade-specific system prompts and preserved Grade 5 behavior.

**Architecture:** Author one validated, source-locked curriculum and register it by full ID. Load Teacher and Gemini Evaluator system prompts from a shared rules file plus a grade directory, constructing one service pair per grade. Use the persisted session Unit to select curriculum, prompt pair, voice recognition context, and browser route.

**Tech Stack:** Python, Pydantic, PyYAML, openpyxl, FastAPI, pytest, Next.js, React, TypeScript, Vitest, Playwright, Pipecat, Soniox.

**Spec:** `docs/superpowers/specs/2026-09-21-grade3-unit1-design.md`

## Global Constraints

- Source: `docs/Global_Success_Khung_Nghe_Noi_3_Level_v3.xlsx`, `Lớp 3 (3 Level)!A2:M4`.
- Preserve stage order `warm-up`, `lesson-01`, `lesson-02`, `lesson-03`, `level-02`, `level-03`, `free-talk`, `summary`.
- Lesson 3 reviews Lesson 1–2; `numbers 20–100` is a range, not many generated targets.
- Engine owns progression and evidence; prompts must not change that authority.
- Unknown curriculum or missing grade prompt fails clearly, without Grade 5 fallback.
- Preserve `/unit1`–`/unit5` and persisted `grade05.*` sessions.
- Keep existing providers and the learner identity Quang; do not require real names, ages, locations, or family details.

## Review Focus

- Grade 3 and Grade 5 both have Unit 1: selecting either must produce its exact ID and content; Tasks 2 and 5 test this.
- Missing grade prompt: runtime must fail instead of selecting Grade 5; Task 3 tests this.
- Unit 3 Lesson 3 workbook review cells: no “Ôn tập” objective or cross-unit target; Task 1 tests this.
- Voice context after resuming an older Grade 5 session: use that session's Unit, not the last selected Unit; Task 4 tests this.
- Grade 3 Free Talk learner gives a real name/age/location: do not demand, invent, or echo private details; Tasks 1 and 6 test this.
